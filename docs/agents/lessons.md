# 合并后复盘教训

代码大量由 agent 编写和评审。定时任务（或手工）复盘前一天合入 `main` 的 PR：
哪些修了刚合入的东西、哪些不该那样合、哪些验证得太薄。学到的东西记在这里。
**改代码前读一遍。**

每条教训是一条规则，然后是为什么，然后是证据。「出现」统计的是在多少个不同日期被复盘到。
出现 ≥3 天，或只出现一次但代价高（资损、生产/预发不可用、错误数据写入生产、权限越界），
会在每周 fold 时沉淀进 `RULES.md`、模块 README 或对应 skill，并移到文末「已沉淀」。

机制与筛选标准见 `skills/pr-lessons/SKILL.md`。
